# Gate Proyecto 000 Demo

El Proyecto 000 Demo está bloqueado hasta que el motor pase auditoría M02 y M03.

## Condiciones de apertura

- MOTOR_AUDIT=PASS
- MOTOR_ADVERSARIAL_AUDIT=PASS
- VALIDATORS_FAIL=0
- BLOCKING_WARNINGS=0
- FAIL_CODES=[]
- CREATIVE_OUTPUT_CERTIFIED=FALSE

## Si el Demo falla

Clasificar causa raíz:

- proyecto;
- prompt de creación;
- motor;
- runtime;
- vendor limitation;
- seguridad.

Si la causa raíz es motor, corregir motor y regenerar o migrar Demo.

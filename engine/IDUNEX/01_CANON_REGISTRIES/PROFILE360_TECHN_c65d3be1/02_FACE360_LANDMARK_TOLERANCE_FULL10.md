## Profile360 integration
This module is not isolated. It links to Profile360 FULL60 fields, Model Causality FULL10, Project Factory, Agent Factory, prompt packs, QA, fallback fixes, sidecar fields, hash and lineage.

Required trace:
Research Source -> Source Card SRC_### -> Profile360 Field ID -> Technical Extension Field -> Project Core Rule -> ChatGPT Agent Rule -> Copilot Agent Rule -> Prompt / Output / QA / Sidecar.

Runtime rule:
If the field is not usable in prompt, QA, fallback, sidecar, hash and lineage, it is not considered productive runtime evidence.


## Field status
- Existing approved canon remains `USER_APPROVED_LOCKED`.
- New values generated by the factory must be `FACTORY_DEFINED_PROPOSED`.
- A proposed value becomes `USER_APPROVED_LOCKED` only after explicit approval and changelog evidence.

## Prompt integration
Every active field must be usable by the prompt pack sections:
A) HEADER, B) SCENE, C) COMPOSITION, D) LIGHTING, E) WARDROBE/PROPS, F) CAMERA/TECH, G) NEGATIVE / AVOID, H) PARAMS, I) QC CHECKLIST.

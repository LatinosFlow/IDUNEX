# IDUNEX project template v1.0.0

This is a declarative pointer, not a second materialized Project Factory. The only active generator is:

`03_PROJECT_FACTORY/02_PROTOCOLS/IDUNEX_PROJECT_FACTORY_v1.0.0.py`

It creates the complete canonical project tree transactionally from one to ten fictitious adult models, then builds and reopens the ZIP, verifies its companion and executes the canonical project validator. A template directory is never a delivery artifact.

# Startup Capability Menu - LEGACY_NON_AUTHORITY

When ChatGPT or Copilot loads the motor and the user has not provided a concrete operation, present this brief menu:

1. Crear proyecto nuevo.
2. Crear proyecto demo generico.
3. Actualizar proyecto con motor nuevo.
4. Actualizar solo proyecto.
5. Aplicar corrección quirúrgica al motor.
6. Downgrade/remoción controlada.
7. Retirar/archivar proyecto.
8. Auditar motor.
9. Auditar proyecto.
10. Generar prompt/output con sidecar y QA.

Then ask for mode: Automático, Básico guiado or Detallado.

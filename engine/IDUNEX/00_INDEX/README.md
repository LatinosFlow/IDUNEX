# IDUNEX Motor v1.0.0

Motor canonico corregido directamente en H341-H360. La version semantica oficial es exactamente `v1.0.0`.

Este motor contiene reglas, schemas, validadores, factories, templates genericos, contratos y politicas. No materializa datos reales de proyectos como defaults activos.

El POST_ENGINE_DEMO_VALIDATION_PROJECT debe generarse despues del cierre del motor como proyecto real de validacion, no como fixture del motor.

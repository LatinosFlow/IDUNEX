# ADR-0001 — Autoridad técnica del repositorio IDUNEX

## Estado

EN_REVISION

## Decisión

GitHub será la autoridad técnica para código, estructura, pruebas, issues, pull requests, workflows y releases del motor IDUNEX.

## Límites

- GitHub no reemplaza SharePoint/OneDrive como autoridad documental empresarial.
- Las conversaciones de ChatGPT no son release oficial.
- Los certificados recibidos son referencia hasta recomputación independiente.

## Consecuencia

Todo hallazgo técnico debe cerrarse por Issue → prueba → corrección → Pull Request → auditoría → merge.
